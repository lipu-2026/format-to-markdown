GOOD TO KNOW
格式与使用说明
可提取正文和结构
DOCX、PPTX、XLSX、XLS、CSV / TSV、带文字层的 PDF、HTML、EPUB、Jupyter Notebook、纯文本、Markdown，以及常见代码 / JSON / XML / YAML。
这些内容需要额外注意
扫描 PDF 与图片还不支持文字识别（OCR）。图片仅生成引用或嵌入原图；音视频、旧版 DOC / PPT 暂不支持。请先用原软件导出为支持的格式。
Word / PPT 中的图片、复杂 PDF 排版和图表可能遗漏信息，请对照原文件检查。Excel 保留公式文本。ZIP 提取文件清单及小型文本文件，Office 文档请解压后单独导入。
怎样交给 AI？
复制结果直接粘贴，或下载 .md 文件上传。长文可逐段复制；字符数和估算 Token 仅供判断篇幅，模型的实际计数可能不同。
本地与便携
无需登录，无需调用 AI 接口。转换内容不上传云端，也不在本工具内持久保存；请在关闭窗口前导出。预览不会自动加载原文中的外部图片和网页。

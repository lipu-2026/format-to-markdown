墨转 2.0.1 · Markdown 工作台（Windows 便携版）

使用方法
1. 请先解压整个 ZIP。
2. 双击 Format-to-Markdown.exe。
3. 把文件拖入窗口，或在“粘贴内容”中添加文字，点击“转换为 Markdown”。
4. 在“阅读预览”检查结果，在“Markdown”页签修改内容。
5. 可复制、单独下载、合并下载，或 ZIP 打包全部。同名文件会自动编号。
6. 长文使用“分段给 AI”逐段复制，默认每段最多 8,000 字符（不含复制说明）。

重要提醒
- 不要只把 EXE 单独拿出来，app 和 runtime 文件夹也必须保留。
- 不需要安装 Python。
- 文件只在本机处理，不会上传到第三方服务器。
- 需要 Windows 10/11 x64，系统已安装 Edge 或 Chrome。
- 关闭或刷新窗口前请先下载结果；本工具不自动保存文件。
- 每批最多 50 个文件、100 MB，单文件最多 60 MB。

支持格式
PDF、DOCX、PPTX、XLSX、XLS、CSV、TSV、HTML、EPUB、JSON、XML、YAML、
TXT、Markdown、Jupyter Notebook、常见代码文件、ZIP 和图片。

已知限制
- 扫描版 PDF 和图片暂不做 OCR。
- 旧版 .doc/.ppt 请先另存为 .docx/.pptx。
- 表格中的公式保留为文本；图表、内嵌图片和复杂 PDF 排版请对照原文件检查。
- 预览只展示前 16 万字符，复制和下载保留全文；预览不会自动加载外部图片。
- ZIP 转换提取文件清单和小型文本，Office 文件请解压后单独导入。
- 程序尚未进行代码签名，Windows 可能显示“未知发布者”。
- 已嵌入墨转程序图标；如果快捷方式仍显示旧图标，可删除旧快捷方式，再从新版程序重新创建。
